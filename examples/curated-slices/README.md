# Curated slices: code execution and long-context maths

Two authored suites, generated by `scripts/author_slices.py OUTDIR [--seed N]`:

- `code-exec-selection.jsonl` / `code-exec-holdout.jsonl` — 30 + 30 single-function
  Python tasks (families `ce-*`), each graded by executable assertions through the
  pinned `python:3.12-slim` sandbox (`jdewitt.evaluation.grade_python`). Every task
  ships a reference solution that passed and a written mutant that failed; the
  generator refuses to write a suite otherwise.
- `long-context-math-selection.jsonl` / `long-context-math-holdout.jsonl` — 30 + 30
  maths tasks (families `lc-*`) whose prompt is an operations report of ~3.6–4.8k
  characters plus one question; the answer is derived from the seeded draw and
  graded by `grade_math` (correct accepted, perturbed rejected).

Selection and holdout are family-disjoint (first three families vs last three);
`validate_splits` accepts the pair. `slices-provenance.json` records the seed,
per-family counts, file digests and the verification statements.

Regenerating with the same seed produces byte-identical files (proven by running
the generator into two directories and diffing). The slices are an authored
ladder: not benchmark items, no leaderboard claim, and the long-context rows test
reading a report, not reasoning about one.

Join them into a run through the importer's `passthrough` source, one split at a
time; the certified suite files under `verification/` are deliberately untouched.
